Toda chamada leva o seu token no cabeçalho (crie o seu em Minha API):

Authorization: Bearer $INTELLEXIA_TOKEN

Respostas em JSON, com os mesmos números das ferramentas do conector do Claude. Cada rota abaixo lista os campos que devolve; campo sem valor vem null. Listas paginam por limite (até {{ teto_pagina }} por página) e deslocamento (a resposta traz tem_mais e proximo_deslocamento). Erros vêm como {"erro": "..."}; parâmetro desconhecido ou fora do limite é recusado, nunca ignorado. A descrição completa, para ferramentas e IA, está em {{ base_api }}/openapi.json (também pede o token).

Usar no Claude Code

Guarde o token numa variável de ambiente (nunca dentro de um arquivo que vai para o git) e comece pedindo algo assim:

Use a API do IntellexIA (documentação em {{ base_api }}/openapi.json, token na variável INTELLEXIA_TOKEN) para montar uma tela que lista os benefícios B91 indeferidos na 1ª instância de uma empresa, com filtro por vigência.

Pelo conector do Claude também dá: peça "me mostre a documentação da API" ou "crie um token de API para mim".
