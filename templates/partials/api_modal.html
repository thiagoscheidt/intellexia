Como usar

Toda chamada leva o token no cabeçalho. Teste com:

curl -H "Authorization: Bearer $INTELLEXIA_TOKEN" "{{ api_cat.base }}/eu"

No Claude Code, comece pedindo algo assim:

Use a API do IntellexIA (documentação em {{ api_cat.base }}/openapi.json, token na variável INTELLEXIA_TOKEN) para montar uma tela que lista os benefícios B91 indeferidos na 1ª instância de uma empresa, com filtro por vigência.

Respostas em JSON; listas paginam por limite e deslocamento; erros vêm como {"erro": "..."}. Limite de 120 chamadas por minuto por token.
