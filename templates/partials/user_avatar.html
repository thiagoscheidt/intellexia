{# Avatar de um usuário: foto do Google quando houver, inicial em círculo quando não. Foto e nome são sempre explícitos — a macro serve tanto o usuário logado (a header passa o que está na sessão) quanto listas de outras pessoas (Administração de Usuários, Atividade de Usuários, Revisor de Petições). A inicial fica sempre no DOM (escondida quando há foto) porque o `onerror` da imagem precisa de algo para revelar: a URL do CDN pode virar 404 se a pessoa trocar a foto entre um login e outro, e há rede de escritório que bloqueia googleusercontent.com. Sem esse par, o avatar viraria ícone quebrado. A inicial é escondida por `d-none`, nunca por style="display:none": as utilities de display do Bootstrap são `!important`, então estilo inline sem `!important` perde para o `d-inline-flex` do próprio span e os dois avatares aparecem lado a lado. `d-none` funciona porque vem depois na folha de estilo. Dois modos de dimensionamento: - com `size`/`font_size` (px), a macro desenha o círculo — é o caso da header e das listas administrativas; - sem `size`, quem manda é o CSS de `extra_classes` — é o caso das telas que já têm a própria classe de avatar (ex.: `.pr-reviewer-avatar` do Revisor), onde a foto entra sem mudar em nada o visual de quem não tem foto. A paleta da inicial vem de `extra_classes` ou, em lista, de `seed`: passando o id do usuário, cada pessoa ganha sempre a mesma cor e a tabela não vira uma parede de círculos idênticos. #} {% macro user_avatar(picture, name, size=None, font_size=None, extra_classes='', seed=None, title='') -%} {%- set inicial = ((name or 'U')[:1] or 'U') | upper -%} {%- set paleta = ['primary', 'success', 'danger', 'warning', 'info', 'dark', 'secondary'] -%} {%- set cor = ('text-bg-' ~ paleta[seed % (paleta | length)] ~ ' fw-semibold') if seed is not none else '' -%} {%- set forma = 'rounded-circle shadow d-inline-flex align-items-center justify-content-center' if size else '' -%} {%- set dimensao = ('width: %dpx; height: %dpx;' % (size, size)) if size else '' -%} {%- if picture %} {%- endif %} {{ inicial }} {%- endmacro %}
